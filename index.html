Voiceover Studio

The character speaks its own script — there is no background narrator track. Speech uses the voices built into your browser / device, so it works fully offline in this static edition. Studio-grade voices (ElevenLabs) plug in through Settings when a key is connected.

Audio-file download of the spoken voice needs a connected voice provider (ElevenLabs) — browser speech synthesis can be heard but not saved as an audio file. The script itself can always be downloaded.

How lines are handled

✓The visual prompt is never sent to the speech engine — only the speaking script field is.
✓One voice per character, chosen above; the same voice is reused for every scene of the project.
✓Fit guide: at normal speed, roughly 2.5 words per second — an 8-second line is about 20 words.

Settings & Providers

This static edition runs entirely in your browser. Planning, prompts, scripts, voice preview (device voices) and the editor work now. Cloud generation needs provider API keys, which in a production deployment belong on a server — never pasted into a public web page. Until then, requests are recorded below as “Needs provider”.

Run it locally / on GitHub

This studio is one single index.html file. Put it in any folder and run:

python3 -m http.server 8000

Then open http://localhost:8000. The same file can be committed to GitHub as-is — no build step, no server code.
