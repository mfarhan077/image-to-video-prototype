Storyboard Studio

Enter a topic, product, car or idea. With a Hugging Face token, Llama 3.3 70B (Qwen 2.5 72B fallback) writes the concept and scene-by-scene plan for real; if that call fails — or no token is set — AutoFlow clearly falls back to its built-in scene templates. Every scene carries its own image prompt, video prompt, camera, lighting, duration, voiceover line and sound effects, and each scene can render its own image or video on Hugging Face. Edit anything, regenerate a single scene, delete it, or move it up and down.

Voiceover Studio

The character speaks its own script — there is no background narrator track, and the visual prompt is never spoken. With a Hugging Face token (Settings), speech is generated by Kokoro-82M on Hugging Face (SpeechT5 as fallback) and can be played and downloaded below. Without a token, your device’s built-in voices are used and labelled as the fallback.

Voice engine: device voices (fallback — add a Hugging Face token in Settings for Kokoro AI voices you can download).

How lines are handled

✓The visual prompt is never sent to the speech engine — only the speaking script field is.
✓One voice per character, chosen above; the same voice is reused for every scene of the project.
✓Fit guide: at normal speed, roughly 2.5 words per second — an 8-second line is about 20 words.

How AutoFlow works

1. Pick or create a project (top-left).
2. Describe the shot in the composer — the visual prompt is what the camera sees and is never spoken.
3. Open the voice toggle in the composer to add a speaking script: the only words the character says, in its own voice.
4. Use + in the composer to attach images, characters and voices.
5. Build the film in Tools: Storyboard, Automotive, Editor, YouTube.

Real generation runs on Hugging Face — add your token in Settings (stored only in this browser) and the composer, scene buttons, Image Generator, Voiceover Studio and YouTube Studio all generate for real. Without a token, nothing is generated and the app says so.
